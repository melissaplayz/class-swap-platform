# Class Swap Platform

A backend API for HKU SPACE Associate of Social Science students to swap classes.

## 🚀 Features
- Student registration & login (email + password)
- Class management (course code, class no., day, time, room)
- One-to-one swap requests (auto disappear after acceptance)
- Chat system (like Carousell) for communication after swap
